# Protocol References

## TCP

RFC 9293
Transmission Control Protocol.
Use for TCP protocol semantics and header/state behavior.

RFC 5681
TCP Congestion Control.
Use for congestion-control semantics.

RFC 7323
TCP Extensions for High Performance.
Use for window scaling and timestamps.

RFC 2018
TCP Selective Acknowledgment Options.
Use for SACK semantics.

RFC 9000
QUIC transport semantics.

QUIC TLS integration and packet protection.

RFC 9002
QUIC loss detection and congestion control.

RFC 8999
Version-independent QUIC properties.

RFC 9312
QUIC manageability and observability considerations.

## Rule

RFCs define protocol semantics.

Implementation source defines how a particular stack realizes those
semantics.

Neither function names nor implementation logging define the semantic
contract.
